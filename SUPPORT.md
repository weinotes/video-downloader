# Support

Thanks for using **Video Downloader**!

## Community Support

- **Documentation**: See [README.md](README.md) and [QUICK_REFERENCE.md](QUICK_REFERENCE.md)
- **Issues**: Report bugs or request features via [GitHub Issues](https://github.com/weinotes/video-downloader/issues)
- **Discussions**: Start a discussion on the [GitHub Discussions](https://github.com/weinotes/video-downloader/discussions) page

## Before Asking

1. Check the [FAQ](README.md#faq) in the README
2. Search [existing issues](https://github.com/weinotes/video-downloader/issues) — yours may already be answered
3. Make sure `yt-dlp` is up to date: `pip install -U yt-dlp`
4. Include verbose logs when reporting issues: `yt-dlp -v "URL"`

## Reporting Issues

If you still need help, please open a [bug report](https://github.com/weinotes/video-downloader/issues/new?template=bug_report.md) with:

- A clear description of the problem
- Steps to reproduce
- Error logs (if any)
- Your OS and Python version
