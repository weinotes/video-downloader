## How to Contribute

1. **Fork** the repo on GitHub
2. **Clone** your fork locally
3. Create a **feature branch** (`git checkout -b feature/my-feature`)
4. Make your changes
5. **Commit** with a clear message
6. **Push** to your fork
7. Open a **Pull Request**

## Development Setup

```bash
git clone https://github.com/weinotes/video-downloader.git
cd video-downloader
pip install -U yt-dlp
```

## Guidelines

- Keep the CLI simple — this tool targets users of all skill levels
- Add type hints for new functions
- Test with at least one YouTube and one Bilibili URL
- Update `CHANGELOG.md` for user-facing changes
